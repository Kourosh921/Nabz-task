# NABZ TASKS — سورس برنامه اندروید

این بسته شامل سورس پروژه اندروید و گردش‌کار GitHub Actions برای ساخت APK است؛ **خود فایل APK آماده نصب نیست**.

## امکانات
- فهرست اولیه کارهای روزانه نبض دلار
- افزودن، ویرایش و حذف کارها
- ذخیره وضعیت تیک‌ها روی گوشی
- صفر شدن تیک‌ها با تغییر روز
- ویجت صفحه اصلی اندروید برای نمایش فهرست کارها
- گردش‌کار ساخت APK در GitHub Actions

## ساخت APK
پس از قرار گرفتن تمام محتویات این پوشه در ریشه مخزن GitHub، از تب Actions گردش‌کار `Build NABZ TASKS APK` را با گزینه `Run workflow` اجرا کنید. فایل خروجی در بخش Artifacts همان اجرای workflow با نام `NABZ-TASKS-debug-apk` قرار می‌گیرد.

## افزودن ویجت
پس از نصب APK، روی فضای خالی صفحه اصلی گوشی لمس طولانی کنید، وارد Widgets شوید و ویجت `NABZ TASKS` را به صفحه اضافه کنید. رفتار و ظاهر ویجت ممکن است بین لانچرهای اندروید کمی متفاوت باشد.
